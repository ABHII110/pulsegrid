Every endpoint in orbit

One service to watch your entire stack

Stop finding out from your customers. PulseGrid checks, records, alerts and reports — so the first person to know something broke is you.

Scheduled probes

GET or HEAD checks from every 10 seconds to once a day, run with bounded concurrency and a hard timeout.

Incident lifecycle

An incident opens after the failure threshold you choose and resolves itself on the very first healthy check.

Signed webhooks

Every opened and resolved incident is POSTed to your endpoint with an HMAC-SHA256 signature you can verify.

Uptime reports

Uptime percentage and average latency over any window, plus the full history of every check you ran.

Scales out

Run one worker on SQLite or many on PostgreSQL — Redis locks make sure no endpoint is ever probed twice.

Secure by default

Private and loopback targets are blocked, redirects are never followed, and API keys are checked in constant time.

Built for on-call calm

Feel the pulse of every endpoint in real time

Each golden ping on the globe is a probe. PulseGrid records its latency, flips the monitor up or down, and keeps a clean incident timeline — readable from the REST API, the CLI, or your own dashboard.

Start watching your endpoints in minutes

Run it on SQLite on your laptop, or ship the Docker Compose stack with PostgreSQL and Redis. Three commands and the worker is probing.

$ uv sync && uv run pulsegrid db upgrade
$ uv run pulsegrid monitors add example https://example.com
$ uv run pulsegrid worker
